## 1. 개요

### 한 줄 정의

**어근(어원 조각)에 눈을 익숙하게 만들어, 의학용어를 "내가 아는 조각들의 조합"으로 *읽어내게* 하는 모바일/웹 학습 앱.** 조합하는 행위 = 의학용어를 파악하는 행위.

### 제품 목표

- **북극성** — 의학용어 *빠른 암기*. 통째 암기(❌)가 아니라 어근 조합으로 *읽어내기*(✅).
- **레버리지를 체감시킨다** — "어근 N개를 익히면 용어 M개가 그냥 읽힌다." 진척은 *읽히게 된 용어 수*로 보여준다.
- **닫힌 루프를 굴린다** — 강의자료(수확) → 어근/용어 그물(자산) → 학습(소비) → 학습 로그 → 약점 가중 복습 큐(적응) → 다시 학습. 이 루프가 닫히는 것 자체가 단품으로 복제 불가능한 도메인 자산. (AI는 *수확*에 산다 — 적응은 데이터 분석으로 복습 큐에 녹임.)
- **수단 = 어원**(암기 가속 렌즈), **장식 = 게임화**(XP·스트릭·랭킹·마스코트는 동기 장치일 뿐, 화면의 주인공은 항상 어근/용어).

### 배경

- 의생명/의학 전공자는 방대한 영어 의학용어를 한국어 뜻 + 라틴/그리스 어원과 함께 외워야 한다. 대부분 통째 암기에 의존해 비효율적이다.
- 의학용어는 **유한한 어근의 조합**으로 구성된다 (`tachy + cardi + ia` → 빈맥). 어근은 유한·고레버리지 자산, 용어는 그 자산이 해금하는 열린 보상 집합이다.
- 이 앱은 수업 과제이기도 하다. 평가축 = **본인 도메인 데이터셋 + 그걸 다루는 에이전트 + (가능하면) 로컬 AI + evaluation 루프**. 단순 앱이 아니라 대체 불가능한 도메인 자산이 핵심.
- **출발점 — 어원은 "수단"이 아니라 차별성을 발견한 지점.** 처음 목표는 그냥 "의학용어 암기를 돕는 서비스"였다. 그 문제를 *어원으로 풀어보니*, 어원 자체가 차별점이라는 걸 발견했다 — 통째 암기 대비 레버리지("어근 N개 → 용어 M개"), 그리고 복제 불가능한 도메인 자산(어근 그물). 그래서 어원을 부수 정보가 아니라 **제품의 중심축**으로 재설정했다.
- 초기엔 게임(캠퍼스 맵·RPG 전투·마스코트)이 주인공이고 의학용어가 콘텐츠 소재였으나, 그 목적-수단 위계도 함께 바로 세우는 중. 시각 톤·인프라(SvelteKit/Tailwind/Paraglide/PWA)는 유지하되 구조를 "어근 1급 데이터"로 재정립한다.

## 2. 문제 및 해결 방안

### 사용자 문제

1. **암기량 폭발** — 외울 용어가 수천 개. 통째 암기는 금방 한계.
2. **어원의 잠재력을 못 쓴다** — 어원이 강력한 가속 렌즈인데, 기존 학습은 어원을 용어의 부수 정보로만 다뤄 "조합으로 읽어내는" 능력으로 이어지지 않는다.
3. **무엇을 복습할지 모른다** — 단순 SRS는 단일 신호(경과 시간)만 본다. 정답률·응답 속도·최근 등장이 얽힌 *약점 패턴*은 못 잡는다.
4. **내 강의자료와 동떨어진다** — 시판 앱의 단어 세트는 내 수업 진도/시험 범위와 맞지 않는다.

### 해결 방안

| # | 해결 | 화면/메커니즘 |
|---|---|---|
| 1 | **어근 친숙화** — 어근이 즉각 떠오를 때까지 빠른 드릴 + SRS | `/classroom` 강의실 (어근 단위 플래시카드, 좌우 스와이프 자가평가) |
| 2 | **용어 추론(디코딩, 주 메커니즘)** — 처음 보는 영어 용어를 아는 어근으로 *쪼개 의미를 읽어낸다*. **가이드된 추론**: 끊는 자리(어근 경계)는 앱이 주고(분해 부담 제거), *각 조각 뜻 회상 → 전체 뜻 추론*은 사용자가. 조각 뜻을 보여주느냐가 **난이도 축**(쉬움=조각뜻 보여줌·이어붙이기 / 보통=조각뜻 숨김·어근 회상 / 어려움=통째 자유회상). 출제는 *부분 어근이 이미 친숙한 용어 우선*(아는 조각 ⊂ 그물) → 레버리지 체감. 뜻→용어 조립(인코딩)은 옵션/심화로 강등 | `/library` 도서관(차분한 추론 퍼즐) · `/ward` 병동(임상 맥락+속도 추론). 난이도 picker가 위 축 |
| 3 | **약점 가중 복습 큐** — "오늘 복습할 어근"이 시간(SRS due)만이 아니라 *약점 점수*(정답률·응답속도·최근 등장·간격을 데이터 분석)로 구성·정렬된다. due가 안 됐어도 약한 어근을 앞으로 끌어옴. 별도 버튼/화면 없이 *복습 큐 하나*에 녹임. LLM 호출 없음. | `/classroom` 강의실 복습 큐 (캠퍼스 "오늘 복습할 어근"이 진입점) |
| 4 | **강의자료 수확(에이전트 = AI의 자리)** — PDF/PPT → 용어 추출(자유텍스트=시맨틱 검색) → 어근 분해 → **RAG로 신뢰 출처(NBK 등) 대조 + citation**(어근표=구조 lookup) → `verified:false` 후보. **정확성은 RAG·출처가 판정**, 사람(검수자)은 *애매한 것만* 편집 판단(↓ 검수자 역할 참고) → 그물에 합류. 환원 불가능하게 LLM이 필요한 유일한 곳 | 별도 standalone 파이프라인 (코어 앱은 그래프 소비자, 에이전트는 생산자) |
| — | **어근 1급 데이터** — `morphemes[]`가 1급, `term.parts: morphemeId[]`로 용어 = 어근 조합 정의. 도감도 어근 그리드가 1급 | `morphemes.ts` / `terms.ts` / `/dex` |

### 차별점

- **어원이 주인공** — 도감·진척 지표·뱃지·랭킹 전부 *어근 기준*("어근 N개 친숙 · M개 마스터"). 어근 = 모으는 자산, 용어 = 해금되는 보상.
- **누적은 날(day)이 아니라 시험(cram)마다 — 벼락치기 복리** — 데일리 *습관*을 스파인으로 두지 않는다(대다수가 벼락치기로 학습 = 행동과 싸우면 진다). 대신 어근 그물이 *시험을 거칠 때마다* 자란다: 중간 벼락치기로 익힌 어근은 시험이 끝나도 안 사라져 기말 범위의 절반을 이미 친숙하게 만들고 다음 벼락치기를 짧게 만든다. **통째 암기 벼락치기는 매번 0에서 시작(증발)하지만, 어원 벼락치기는 자산이 시험 사이에 복리로 쌓인다 = 안티-증발.** 이게 결제 명분(벼락치기 모먼트 WTP)도 키운다. SRS·데일리는 스파인이 아니라 *시험 사이 망각을 늦추는 얇은 접착제 + 더 일찍 누적하는 선택 경로*로 강등. 닫힌 루프는 그대로 닫힌다 — 누적 cadence가 날→시험으로 바뀔 뿐.
- **AI를 레일 위에** — 자유 챗봇/프롬프트 입력창 없음. 사용자는 *올리고·따라가고·누르기만* 하고, 프롬프트 엔지니어링·워크플로 설계는 앱이 대신한다. AI를 쓸 줄은 알아도 *학습에 효율적으로 쓰는 법*은 모르는 사용자에게, 그 검증된 방식을 레일로 깔아준다 — "내가 직접 프롬프트 짜며 시행착오 안 해도, 따라가기만 하면 학습에 최적화된 AI 사용이 된다"가 매력 포인트.
- **닫힌 루프 = 복제 불가 자산** — 수확(입력) ↔ 약점 가중 복습 큐(출력)가 같은 그물 위 두 면. 자료가 자산을 키우고, 자산이 학습을 굴리고, 학습이 로그를 쌓고, 로그가 다음 학습을 조준.
- **데이터 신뢰성 = 출처 기반(사람 권위 아님)** — 어원·뜻 정확성이 핵심(의학 앱). 진짜 권위는 *누구의 지식*이 아니라 **인용한 신뢰 출처**(NBK OER 교재 등). 검증 = "답을 아는 것"이 아니라 *출처와 맞춰보는 것* → RAG가 그 대조를 자동화하고 citation을 단다. 외부/자동 생성 항목은 `source` + `verified:false`로 격리, `validate-data.mjs`(구조 검증) + RAG 대조 통과분만 학습 큐. 어느 출처에도 없으면 **안 가르침**(후보로만 도감 검색에 노출). 사람은 정확성 검증자가 아니라 *애매한 것 편집자*.
- **단순 SRS와의 선** — 보통 SRS는 *시간 하나*로 복습 큐를 짠다. 우리 큐는 다중 신호(정답률·응답속도·최근 등장·간격)로 약점을 점수화해 *due가 아니어도 약한 어근을 끌어온다* — 같은 복습 큐 하나에 녹인 게 차별점. 전부 결정적 데이터 분석 — LLM 불필요(비결정·비용·라이브 실패 리스크 회피). *AI는 런타임이 아니라 오프라인 콘텐츠 생성(수확·`meaningKo` 드래프트·헷갈리는 어근 쌍 라벨링)에 산다.* 의미 지식은 한 번 미리 만들어 데이터에 박고, 런타임은 순수 조회.

## 3. 타겟 및 시나리오

### 타겟 사용자

- **1차** — 의학용어를 영어↔한국어+어원으로 외워야 하는 의생명/의학 계열 전공자(학부 저학년, 의학용어 수업 수강생).
- **2차** — 간호·물리치료·임상병리 등 보건 계열, 의학용어 시험/자격 준비자.
- **공통 특성** — 모바일로 짧게 자주, 강의자료(PDF/PPT) 기반 시험 범위가 명확. AI 도구 자체는 이미 쓰지만(ChatGPT 등) *학습에 효율적으로 쓰는 방식*은 모른다 — 무엇을 물어야/시켜야 학습이 빨라지는지 모름(→ 레일 위 AI가 그 효율적인 방식을 대신 설계).

### 사용자 시나리오

**A. 시험 벼락치기 (스파인 — 강의자료 없이도 완전 동작)**
> 시험 D-3. 캠퍼스에서 "지난 시험들로 모은 어근 N개 → 이번 범위 M개가 *이미* 풀림"을 본다(누적 복리). 응급실(`/emergency`)에 들어가 범위·남은 시간을 주면, 앱이 *결정적으로* 레버리지×약점×범위포함도로 정렬해 **"90분 압축 코스: 어근 18개 → 시험범위 64개 커버"**를 짠다 → 좌우 스와이프로 빠르게. **이 압축은 통째 암기와 달리 어근을 *남겨서***, 시험이 끝나도 다음 시험 벼락치기를 짧게 만든다(복리). 장기기억은 시험 후 약점 가중 복습 큐가 받는다.
>
> *선택적 데일리 경로* — 등하교 길에 캠퍼스 → 강의실 복습 큐(약점 가중: 며칠 정답률이 흔들린 `-emia`·`hyper-`가 due 아니어도 앞으로, "최근 약한 어근" 라벨만 살짝) → 도서관에서 처음 보는 용어를 오늘 익힌 어근으로 *쪼개 읽으며* 마무리. 강제 스파인이 아니라 *자산을 더 일찍 쌓아 벼락치기를 더 짧게* 만드는 가속 경로.

**B. 강의자료 수확 (개인화/프리미엄 레이어)**
> 노트북에서 이번 주 강의 PDF를 올린다 → 수확 에이전트가 용어 추출·어근 분해 → RAG로 NBK 등과 대조해 출처 단 후보를 만든다 → *대부분은 이미 검증된 어근으로 쪼개져 자동 통과*, 출처에 없거나 애매한 새 어근 몇 개만 검수자에게 → 통과분이 그물에 합류 → *그 자리에서 바로* 그 세트로 드릴 → 한 웹 세션 안에서 루프가 닫힌다.
>
> (발표 데모: 라이브 LLM 호출 없이, *미리 처리한 실제 강의자료* 결과를 보여주고 학습으로 흐름.)

## 4. 성공·위험 요소

### 핵심 지표

| 축 | 지표 |
|---|---|
| **학습 효과(북극성)** | 친숙 어근 수 / 해금(읽히게 된) 용어 수 — *레버리지 비율* (어근 1 증가당 용어 몇 개 해금) |
| **유지(누적 복리)** | 시험 간 어근 잔존율, *다음 벼락치기 단축*(새 시험범위 중 이미 친숙한 어근 비율), 재방문 / (보조) 데일리 골·스트릭 |
| **적응(약점 가중 큐) 가치** | 약점 어근이 큐 상위에 오는 비율, 복습 세션 완료율, 약점으로 끌어온 어근의 사후 정답률 개선 |
| **AI(수확) 가치** | 어원 분해 정확도, **groundedness**(인용 출처가 실제로 그 뜻을 지지하는 비율), RAG 자동 통과율(=사람 안 거친 비율), 수확 1회당 새로 합류한 어근/용어 수 |
| **데이터 자산** | 검수 완료 어근/용어 수, 어근당 평균 용어 등장 수("그물 밀도", 현재 1.64 → 목표 2~5) |
| **수확 파이프라인** | 추출/어원분해 정확도(evaluation), 검수 통과율 |

### 리스크

| 리스크 | 영향 | 완화 |
|---|---|---|
| **그물이 얇다** — 어근 71%가 1회만 등장, 레버리지 체감 약함 | 핵심 가치 미전달 | 후보 검수 머지 → 어근당 2~5 용어 겹치도록 콘텐츠 보강 |
| **자동 생성 데이터 오염** — NER/어원분해 오류가 학습 큐 직행 | 학습 신뢰 붕괴(의학 앱) | `verified:false` 격리 + `validate-data.mjs`(구조) + **RAG 출처 대조(정확성)** + 애매한 것만 사람 편집. 출처 없으면 학습 큐 제외 |
| **무대 라이브 LLM 실패** | 발표 데모 리스크 | 옵션 C — 개발 시점에 미리 구워 박음, 데모는 처리된 결과 시연 |
| **스코프 과대** — 2.5주에 루프 전체 깊게 불가 | 미완성 | 발표 = 루프 한 바퀴 관통하는 얇은 vertical slice. 거부 목록 준수(자유 분해 입력·mnemonic 자동생성·채팅 튜터·WebLLM·신규 화면 = 모두 ❌) |
| **현재 모드가 학습 목적과 역방향** — 도서관/병동이 한→영(역방향), 디코딩 모드 0 | 목적 미스매치 | 도서관/병동을 디코딩(영어 분해→의미 조립) 테마로 재정의 |
| **게임화가 다시 주인공 됨** | 목적-수단 위계 붕괴 | 게임 요소는 chrome, 시간 적게. 주인공 자리 = 어근/용어 |

## 5. 속성 설정

### 카테고리

교육 / 의학·헬스케어 / 어학 암기 (의학용어 어원 학습) · AI 학습 보조.

### 사용자 역할

- **학습자(Learner)** — 유일한 주 사용자. 어근 친숙화·조합 학습·추천 복습 소비. (역할 구분/권한 시스템 없음, 단일 역할.)
- **검수자(Curator)** — *내부/개발 역할*. **정확성 검증자가 아니라 편집자.** RAG·출처가 정확성을 판정하므로, 검수자는 RAG가 자동 통과시킨 대부분은 건드리지 않고 *애매한 것만* 처리: ① 출처에 없음 → 버릴지(go/no-go), ② RAG 신뢰도 낮음 → 슥 확인, ③ 뜻 다중(예 `myel/o`=골수/척수) → 무엇을 가르칠지 고르기, ④ 출처 충돌 → 채택 선택, ⑤ `meaningKo` 우리말 표현 작성(번역 아님). 의학 지식 없이 가능한 편집 판단. 그물이 클수록 "애매한 것"은 새 어근 수로 수렴(줄어듦). 앱 런타임 역할 아님 = 데이터 파이프라인 단계.
- **학습자는 검증자가 아니다** — 사용자는 올리고·배우고·가끔 "이상해요" 신고만(선택). 배우러 온 사람에게 정답 판단을 시키지 않음.
- 백엔드/계정 없음 — 진행도·프로필·SRS는 localStorage. (OAuth는 미연동, Google/게스트 둘 다 온보딩행.)

### 기기

- **모바일 우선** — 모바일 웹앱 + PWA(홈 화면 설치). 데일리 학습의 기본 폼팩터. 데스크톱은 `max-w-[420px]` 센터 컬럼.
- **데스크톱/웹** — 강의자료 *수확·검수*(넓은 화면 + PDF 뷰어 + 검수 테이블)와 빠른 웹 학습. 앱이 이미 SvelteKit/PWA 웹이라 '플랫폼 이식'이 아니라 '데스크톱 레이아웃 추가' 문제.
- **수확 에이전트** — standalone 파이프라인(개발 시점 Claude Code 실행, API/로컬모델로 교체 가능하게 설계). 코어 앱과의 유일한 접점 = `morphemes.ts`/`terms.ts` + `validate-data.mjs`.

## 6. 비즈니스 모델 — 하나의 엔진, 두 흡입구

> 단독 사업이 아니라 *쐐기 + 확장 경로*로 정직하게 제시. 평가축은 매출이 아니라 도메인 자산(§1 제품 목표)이므로 BM은 가설+테스트로 둔다.

### 한 줄

**보정사 시험으로 "돈 되는 메커니즘"을 증명하고(쐐기), 강의자료 수확으로 보정사 밖 모든 의학용어 학습자에게 확장한다(레버리지).** 둘은 별개 제품이 아니라 *같은 어근 그물 엔진*에 범위를 채우는 두 흡입구일 뿐.

### 쐐기 = 보건의료정보관리사(보정사)

- **왜 보정사** — 의학용어가 *채점되는 과목*(68문항 묶음)인 거의 유일한 시험. 의학용어 **단독 교재 8만원이 실제로 팔림** = 돈 흐름이 검증된 시장. 비전공 다수라 어원 절실. 제품 적합도 100%(현 그물 = NBK word-part = 보정사 의학용어 그 자체, 콘텐츠 재작업 0).
- **범위가 국가에 고정** — 의학용어 = **14개 신체계통**(소화·호흡·순환·혈액림프·내분비·근골격·신경정신·여성생식·임신출산·남성생식·비뇨·외피·감각 등)이 전 응시생 동일. → 한 번 큐레이션하면 응시생 전원에게 맞음 = **콘텐츠 공급 1:N(ROI 최고)** + "시험범위 커버율 %"라는 유한·검증가능한 진척 지표.
- **메커니즘 증명** — 제40회 합격자 후기 *"기본(어근)만 잘해도 짜집기 가능, 진짜임"* = 제품 북극성("어근 조합으로 읽어내기")을 합격자가 독립적으로 같은 결론. 시장 증명(8만원 교재)보다 귀한 메커니즘 증명.
- **한계는 정직하게** — 모집단 ~3,000/년으로 작아 단독 사업은 안 됨. **그래서 "여기서 끝"이 아니라 발판.** 보정사는 매출이 아니라 ① 어근 그물을 시험범위만큼 두껍게 만들 수 있음, ② 메커니즘 작동, ③ 지불 의사 실재 — 이 셋을 *증명*하는 자리.

### 확장 = 강의자료 수확 (보정사 그물이 종잣돈)

- **진짜 고통 = "내 시험범위와 정합"**(§2 문제 #4). 보정사는 범위가 고정이라 우리가 채우면 되지만, 일반 학부생은 학교·교수마다 범위가 달라 *개인화 필요* → **강의 PDF 업로드 → 수확 에이전트가 용어 추출·어근 분해 → 내 시험범위가 그대로 학습 세트.**
- **핵심 시너지 — 보정사 그물 = 모든 후속 학습자의 베이스라인.** 의학용어는 유한 어근의 조합이라, 14계통을 검증된 어근으로 채우면 *이미 다른 의학용어 수업의 상당 부분을 덮는다*. → 학생이 PDF를 올려도 **콜드스타트 없이 새 어근 몇 개만 합류**. 보정사에 들인 큐레이션 비용이 **확장의 종잣돈**이 됨.
- **"더 나은 플래시카드 앱" 함정 회피** — 공짜 Anki/ChatGPT는 *내 자료를 출처보증된 어근 그물로* 만들어주지 않음. 수확(출처 대조 + 어근 정합)이 그 차이.

### 퍼널

| 티어 | 내용 | 채널 / 가격 |
|---|---|---|
| **0 (무료 퍼널)** | 내장 14계통 어근 친숙화 드릴 일부 | 누구나 |
| **1 (소액 artifact — 실거래 증명 목표)** | 보정사 전범위 검수 어근 그물 → Anki덱/PDF/노션 export | 보정사 카페·오픈채팅(광고비 0), 3~9천원 |
| **2 (수확 — 프리미엄, Phase 2)** | 내 강의자료 업로드 → 내 시험범위 그물 + 압축코스 | 보정사 인강 교안·학부 강의 공통. 인강의 *보완재* 포지션 |

> Tier 1 목표 = 타당성 증명(슬라이드)을 넘어 **실거래 1건.** 전제 = 그물이 보정사 범위를 덮을 만큼 두꺼워 미리보기가 안 부끄러울 것 → *돈 작업 ↔ 그물 보강이 한 점에서 만남.*

### 경고

- **스코프** — 실시간 임의 PDF 업로드는 Phase 2(↓부록 거부 목록). 발표 데모로 당기려면 라이브 LLM 없이 **보정사 범위와 겹치는 강의자료 1개를 미리 처리**해 "업로드 = 대부분 자동 디코드 + 새 어근 몇 개만 합류 → 그 자리서 드릴" 한 흐름만 시연(레버리지+수확+보정사 적합을 한 데모에 묶음).
- **주인공** — 강의자료 수확은 *범위 정합을 자동화하는 수단*. 주인공 자리는 계속 어근 그물(목적-수단 위계 유지).
